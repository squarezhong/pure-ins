# Pure Ins

Following, not recommended.

适用于 Instagram 网页端的油猴脚本：关注优先，清理推荐和已识别的广告，保留主动搜索与日常互动。

## 功能

- 默认隐藏 Home 入口；打开首页或点击 logo，进入本人主页。恢复显示 Home 后，点击 Home 可浏览原生首页。
- 首页中间信息流仅清理明确广告，保留推荐帖子和未关注作者；清理左右栏推荐、帖子详情的相关推荐。
- 隐藏发现、Reels 和平台推广入口；保留 Search，清理未搜索时的发现推荐网格。
- 隐藏 Reels 推荐大厅；直接打开具体短视频时保留当前视频，清理后续推荐与推荐切换控件。
- 始终隐藏 Notifications 入口的红点和数字徽标。
- 保留 Stories、个人主页及其 Reels 列表、收藏、私信、通知、发布、评论、分享和图片轮播。

面向 Instagram 桌面网页版，匹配 `instagram.com` 和 `www.instagram.com`。内置英文、简体中文和繁体中文标记，不修改原生 App。

## 安装

需要浏览器装有 **Tampermonkey** 或 **Violentmonkey** 扩展。

### 一键安装

[安装 Pure Ins (GitHub)](https://raw.githubusercontent.com/squarezhong/pure-ins/main/pure-ins.user.js)

该链接在脚本发布到 GitHub `main` 分支后可用，届时可通过管理器获取更新。尚未发布时请使用手动安装。

### 手动安装

在油猴扩展中新建脚本，将 [pure-ins.user.js](pure-ins.user.js) 的全部内容复制进去，替换默认模板并保存；也可通过扩展的本地文件导入功能安装。

安装后刷新 Instagram 页面即可使用。

## 设置

在油猴菜单中打开 **Pure Ins：设置**，可分别调整默认个人主页、隐藏 Home、广告、推荐模块、发现网格、Reels 推荐流、推荐入口和隐藏通知徽标。以上选项默认开启。页面上没有常驻设置按钮。

点击“保存”后生效；取消、Esc 或点击弹窗外部均不保存。“恢复默认”也需要点击保存才生效。页面清理未及时生效时，可使用菜单中的 **Pure Ins：重新应用规则**。

## 使用说明

- 无法确认来源的帖子会保留；普通正文、评论或点赞摘要不会因为出现“推荐”“广告”等词被隐藏。
- 主动搜索、直接打开的帖子和个人主页不按关注关系过滤。个人主页打开的帖子弹窗保留作者列表切换。
- 个人主页通过导航栏的原生入口打开；最多等待 10 秒，无法识别时留在当前页面。关注列表由你手动打开。可见视频采用原生播放行为。
- 脚本隐藏推荐界面，并暂停被隐藏的视频；它不拦截网络请求，不能阻止 Instagram 预加载内容。关闭规则后不会自动恢复视频播放。
- Instagram 改版或未识别的语言可能影响过滤效果；遇到误判可在设置中关闭对应规则。脚本不调用私有接口、不抓取关注名单、不发送遥测。
